# Pizza d'oro Savas — Website

A single-page website for **Pizza d'oro Savas**, a family-run wood-oven pizza restaurant in Archangelos, Rhodes.

## Preview locally

Open `index.html` directly in your browser, or run a simple local server:

```powershell
# Python (if installed)
python -m http.server 8080

# Node (if installed)
npx serve .
```

Then visit [http://localhost:8080](http://localhost:8080).

## What's included

- Hero with rating, price range, and call-to-order
- About section highlighting the family-run, wood-oven story
- Menu highlights (Seafood Pizza, Pizza Special, and more)
- Google review excerpts
- Contact info, hours, and map
- Mobile-responsive layout

## Deploy

Upload the folder to any static host (Netlify, Vercel, GitHub Pages, or your web host). No build step required.
